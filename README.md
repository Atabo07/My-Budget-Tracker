# SpendWise Dashboard

## Week 5 Assignment – Build the JavaScript Foundation

## Project Description

SpendWise is a personal finance dashboard designed to help users view and manage their financial information.

The project was developed from the original Budget Tracker project and continued through the previous weeks.

In Week 5, JavaScript was added to the SpendWise dashboard to transform it from a mainly visual application into an application that can process budgeting information.

The JavaScript allows users to enter their monthly budget and total expenses. The application then calculates the remaining balance and displays the results in the browser console.
